🚀 Work Garage App (Frontend)

A React.js-based project management interface that helps users organize their work using projects and todos. It provides a simple dashboard to manage tasks in a structured way.

📌 Overview

Work Garage App is a frontend-only project focused on building a clean and functional UI for managing projects and tasks.

Users can:

Create projects
Add and manage todos
View everything from a centralized dashboard

This project demonstrates how a project management tool can be structured at the UI level.

✨ Features
📁 Create and manage projects
✅ Add, update, and delete todos
📊 Dashboard to organize tasks
⚡ Responsive and clean user interface
🛠️ Tech Stack
Frontend: React.js
Styling: CSS / (or Tailwind / Bootstrap — update if you used one)
📂 Project Structure
src/
│── components/     # Reusable UI components
│── pages/          # Main pages (Dashboard, Projects, etc.)
│── assets/         # Images, icons, etc.
│── App.js          # Main app component
│── index.js        # Entry point
🚀 Getting Started
1. Clone the repository
git clone https://github.com/anuraggiri-do-it/work-garage-app.git
cd work-garage-app
2. Install dependencies
npm install
3. Run the app
npm start

The app will run on:

http://localhost:3000
