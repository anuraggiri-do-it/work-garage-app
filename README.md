This will:

Start the FastAPI backend server

Terminal after starting application

Accessing the Application
Once started, you can access the application at:

Frontend: Your CloudFront URL + /proxy/3000/ (e.g., https://abc123.cloudfront.net/proxy/3000/)
Backend API: Your CloudFront URL + /proxy/8000/ (e.g., https://abc123.cloudfront.net/proxy/8000/)
You can find your CloudFront URL under the PORTS tab. You can click on the globe icon next to the URL to open the page directly in your browser.

Troubleshooting Common Issues
Important: Only use the following commands when you are facing an issue.

Issue	Solution
Port already in use	Run pkill -f "python|node" then restart
Permission denied	Run chmod +x start.sh
Module not found	Activate virtual environment: source venv/bin/activate
AWS access denied	Environment should be pre-configured, contact instructor
Verification
Once your environment is running:

Verify Application: Access the frontend using your CloudFront URL + /proxy/3000/
Test Chat Interface: Send a simple message
Check Backend: Ensure API responds at your CloudFront URL + /proxy/8000/
Review Code Structure: Explore the ui/backend/mcp_servers/ directory
